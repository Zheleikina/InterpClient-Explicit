# Контракт бібліотеки InterpolationLib (Варіант 3, Студент А)

**Версія API:** 1.0
**Бінарний файл:** `InterpolationLib.dll`
**Імпортна бібліотека:** `InterpolationLib.lib`
**Заголовковий файл:** `InterpolationLib.h`

## Функції

### `double linearInterpolation(double x0, double y0, double x1, double y1, double x)`
- **Призначення:** лінійна інтерполяція між двома точками.
- **Параметри:** `x0, y0` — перша точка; `x1, y1` — друга точка; `x` — точка обчислення.
- **Обмеження:** якщо `x1 == x0`, функція повертає `y0` (без ділення на нуль).
- **Результат:** значення лінійної функції через дві точки в точці `x`.
- **Побічні ефекти:** немає.

### `double lagrange(const double* xs, const double* ys, int n, double x)`
- **Призначення:** обчислення інтерполяційного полінома Лагранжа за `n` вузлами.
- **Параметри:** `xs`, `ys` — масиви розміру `n` (вузли); `x` — точка обчислення.
- **Обмеження:** `xs` і `ys` не повинні бути `nullptr`; `n` повинно бути `> 0`.
- **Помилки:** при некоректних параметрах повертає `0.0`.
- **Пам'ять:** функція НЕ виділяє і НЕ звільняє пам'ять, масиви належать виклику.

### `double interpolate(const double* xs, const double* ys, int n, double x)`
- **Призначення:** кусково-лінійна інтерполяція за масивом вузлів.
- **Обмеження:** `xs` повинен бути відсортований за зростанням; `xs`/`ys` не `nullptr`; `n > 0`.
- **Поведінка поза межами:** екстраполяція по найближчому відрізку.
- **Помилки:** при некоректних параметрах повертає `0.0`.

### `double interpolationError(const double* xs, const double* ys, int n, double x, double trueValue)`
- **Призначення:** модуль похибки інтерполяції Лагранжа відносно відомого точного значення.
- **Результат:** `|lagrange(xs, ys, n, x) - trueValue|`.

## Загальні правила
- Усі функції мають C-зв'язування (`extern "C"`), декорування імен (name mangling) відсутнє.
- Жодна функція не виділяє пам'ять у куп'і для результату — повертаються прості `double`.
- Жодна функція не модифікує вхідні масиви.
- Версія бінарного файлу: 1.0. Сумісність API зберігається, доки сигнатури функцій не змінюються.
